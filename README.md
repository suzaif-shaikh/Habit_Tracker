# 📊 MS Excel Habit Tracker Dashboard

An interactive MS Excel dashboard for tracking daily habits, goals, consistency, and personal progress.

## 📌 Project Overview

This project is an Excel-based Habit Tracker designed to monitor personal habits and goals on a daily, weekly, and monthly basis.

The dashboard provides a clear visual summary of habit completion, progress percentages, consistency levels, and completed/uncompleted habits.

## 🎯 Objectives

- Track daily habits and goals
- Monitor weekly and monthly progress
- Measure habit consistency
- Identify the most and least consistent habits
- Visualize progress using charts and dashboards

## 🛠️ Excel Skills Used

- Excel Formulas
- Conditional Formatting
- Data Validation
- Progress Tracking
- Data Visualization
- Dashboard Design
- Charts
- Percentage Calculations

## 📊 Dashboard Features

- Daily Habit Tracking
- Weekly Habit Tracking
- Monthly Habit Tracking
- Completion Percentage
- Completed & Uncompleted Habits
- Top 3 Most Consistent Habits
- Top 3 Least Consistent Habits
- Progress Charts
- Weekly & Monthly Goal Tracking
